name: video-describe
description: Transcribe speech and describe visuals in videos, GIFs, and round video notes
kind: media
media: video, video_note
---
Analyze the video.

1. If anyone speaks, transcribe the speech in its original language (do not translate).
2. Then describe the key visual content in 1-2 sentences: what is shown, any on-screen text, screens, or demos.

If there is no speech, write only the visual description.
