Summarize the document in 1-3 concise sentences.

- Say what kind of document it is (spec, invoice, contract, log, notes, ...).
- Pull out the key facts: numbers, dates, names, decisions, deadlines.
- If the file can't be read (binary, encrypted, archive), say so and describe it from its name and caption.
